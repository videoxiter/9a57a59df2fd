# Приложение-трей «ОТП» (Windows и macOS)

Один код — два приложения. Значок в трее (Windows) или меню-баре (macOS) показывает
состояние смены и позволяет управлять ей без открытия браузера.

## Что умеет

- Значок цвета состояния: **работает** (зелёный), **перерыв** (жёлтый), **обед** (сиреневый),
  **отсутствие** (голубой), **вне смены** (серый), **нет связи** (красный).
- Меню: «Начать смену», «Техперерыв 1», «Техперерыв 2», «Обед», «Вернуться с перерыва»,
  «Временное отсутствие», «Завершить смену».
- Перед применением — **отсчёт 10 секунд**: в названии пункта видно «… · 9 с», появляется
  «Отмена». **Повторный клик по тому же пункту — применить сразу.**
- «Открыть мою страницу» — личный кабинет в браузере.
- Состояние подтягивается с сервера каждые 20 секунд, поэтому телефон и компьютер видят одно и то же.

## Вход (один раз)

При первом запуске откроется окно: вставь **ссылку на свою страницу** (из сообщения
руководителя, вида `…/team/<код>/start/`) и **пароль**. Токен сохраняется только на этом
компьютере: Windows — `%APPDATA%\OtpTray\config.json`, macOS — `~/Library/Application Support/OtpTray/config.json`.

Чтобы войти заново (например, сменился пароль): удали `config.json` и запусти приложение.

## Windows

1. Готовый файл: `dist\OtpTray.exe` — можно просто запустить двойным кликом.
2. Автозапуск при входе в систему:
   ```
   powershell -ExecutionPolicy Bypass -File install_autostart_windows.ps1
   ```
3. Пересобрать из исходников (если меняли код):
   ```
   .venv\Scripts\pyinstaller.exe --noconfirm --onefile --noconsole --name OtpTray ^
     --icon app\assets\app.ico --add-data "app\tray\icons;icons" ^
     --distpath app\tray\dist --workpath app\tray\build app\tray\otp_tray.py
   ```
4. Удалить автозапуск: `Unregister-ScheduledTask -TaskName 'OTP Tray' -Confirm:$false`.

## macOS

1. Запуск из исходников (первый раз сам поставит зависимости):
   ```
   bash run_macos.command
   ```
2. Собрать .app (двойной клик по приложению):
   ```
   bash build_macos.command      # → dist/OtpTray.app
   ```
3. Автозапуск:
   ```
   bash install_autostart_macos.command
   ```
4. Логи: `/tmp/otp-tray.log`. Удалить автозапуск:
   `launchctl unload ~/Library/LaunchAgents/com.otp.tray.plist && rm -f ~/Library/LaunchAgents/com.otp.tray.plist`.

> На macOS при первом запуске система может спросить разрешение на запуск приложения
> из «неопознанного разработчика»: Параметры → Конфиденциальность и безопасность → «Всё равно открыть».

## Проверка без трея

```
.venv\Scripts\python.exe app\tray\otp_tray.py --selftest
```
Печатает путь конфига, наличие токена, каталог значков и проверяет расчёт состояния.

## Ограничения первой версии

- Горячих клавиш пока нет — только меню значка.
- Временное отсутствие создаётся с причиной «Без заявки».
- Мгновенная отправка в «ДисКо» работает из приложения (как на сайте); если
  сообщение не ушло — его дошлёт `cron` в течение минуты.
