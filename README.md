# Моя команда ОТП

Тёмный интерактивный дашборд эффективности отдела технической поддержки + 10 персональных страниц роста. Статический сайт (HTML/CSS/JS), без бэкенда.

**Живая версия:** https://videoxiter.github.io/otp-team/

## Что внутри

- **`index.html`** — главный дашборд (только для руководителя): рейтинг по среднему KPI, карточки сотрудников, динамика команды, радар с выбором сотрудника.
- **`team/<слаг>/index.html`** × 10 — персональная страница «Мои результаты» с **неугadываемым URL** (случайный 12-значный токен вместо фамилии — сотрудник не догадается о чужой ссылке).
- **`assets/js/data.js`** — единая точка правды (реальные данные).
- Геймификация: звания («Легенда», «Профи»…), ордена («Топ месяца», «Идеальная пятёрка»…), звёзды за рост.
- Рекомендации с фактами — каждый пункт плана ссылается на конкретный тикет (HELP-…).

## Данные

Реальные данные за **апрель–июль 2026** (KPI по 5 метрикам, бонусы, факты-замечания с тикетами), извлечённые из экспорта Qwen-чата. У главного специалиста (Яковленков) KPI не ведётся — страница показывает бонусы и рекомендации.

## Ежемесячное обновление

Раз в месяц, когда приходят новые итоги:

1. Положи новый экспорт чата рядом с `scripts/extract_qwen.py` (или передай путь).
2. Запусти (в git-bash):
   ```bash
   cd G:/LMStudio/otp-team
   PYTHONUTF8=1 python scripts/extract_qwen.py "<путь к export.json>"
   PYTHONUTF8=1 python scripts/generate_data.py
   PYTHONUTF8=1 python scripts/generate_pages.py
   ```
3. Закоммить и запушь:
   ```bash
   git add -A && git commit -m "данные: <месяц>"
   git push
   ```

GitHub Pages подхватит пуш и пересоберёт сайт автоматически (~1 мин). Слаги не меняются — ссылки у сотрудников остаются прежними.

## Стек

GSAP + ScrollTrigger (Apple-скролл), Lenis (инерция), Chart.js (графики с tooltip), Phosphor Icons, шрифты Space Grotesk / JetBrains Mono. Всё с CDN.
