# Синхронизация графика с Confluence — комплект для Павла

## Что это и зачем

На сайте «Мои результаты» есть график смен и отпусков. Он берётся из Confluence
(страницы «Графики рабочего времени» и «График отпусков»). Раньше график
обновлялся вручную с компьютера руководителя. Этот комплект ставит **агента** —
маленькую программу, которая:

1. каждый день в **07:30** сама забирает свежий график из Confluence и публикует его на сайте;
2. **каждые 5 минут** проверяет кнопку «Синхронизировать график» на сайте — если её нажали,
   сразу выполняет синхронизацию;
3. работает в фоне, **без окон и без участия человека**;
4. нужна на второй машине, чтобы синхронизация не останавливалась, когда ПК руководителя
   выключен или недоступен.

Данные сотрудников агент не видит и не меняет — он обновляет только график смен и отпусков.

---

## Что нужно перед началом

- Компьютер под управлением **Windows 10/11** или **macOS**.
- **Python 3** (на macOS обычно уже есть; на Windows — с python.org, при установке
  поставить галочку «Add Python to PATH»).
- **Git** (на macOS — `xcode-select --install`; на Windows — git-scm.com).
- **Логин и пароль Confluence**, под которым можно смотреть графики (можно отдельный
  сервисный логин только на чтение — так даже лучше).
- Доступ в интернет (Confluence — внутренний, значит нужна корпоративная сеть/VPN).

---

## Windows

1. Распакуй архив в любую папку (например, `C:\OTP-sync`).
2. Двойной клик по **`install_windows.cmd`**.
   Если Windows спросит разрешение — разреши (это обычный установщик).
3. Скрипт спросит:
   - **Логин Confluence** — введи и Enter;
   - **Пароль** — при вводе символы не отображаются, это нормально;
   - **Токен GitHub** — если нужно, чтобы обновления публиковались с твоего компьютера.
     Если токена нет — просто Enter (тогда публиковать будет руководитель).
4. Дождись строки **«=== Готово ===»**.
5. Проверка: открой «Планировщик задач» → «Библиотека планировщика задач» → там должны быть
   **OTP Schedule Daily** и **OTP Schedule Watch** в состоянии «Готово».

Удалить: в планировщике удалить эти две задачи (или выполнить в PowerShell
`Unregister-ScheduledTask -TaskName 'OTP Schedule Daily','OTP Schedule Watch' -Confirm:$false`).

## macOS

1. Распакуй архив (двойной клик по zip — появится папка).
2. Открой **Терминал** (Программы → Утилиты → Терминал).
3. Перетащи папку из Finder в окно Терминала — появится путь, допиши команду:
   ```
   cd <путь к папке> && bash install_macos.command
   ```
4. Скрипт спросит:
   - **Логин Confluence** и **пароль** (пароль при вводе не виден);
   - **Токен GitHub** — можно пропустить (Enter).
5. Дождись строки **«=== Готово ===»**.
6. Проверка: в Терминале `launchctl list | grep otp.schedule` — должны быть две строки
   `com.otp.schedule.daily` и `com.otp.schedule.watch`.

Логи: `/tmp/otp-schedule-com.otp.schedule.watch.log`
Удалить: `bash ~/OTP-site/scripts/macos/uninstall_macos_agent.command`

> Первый запуск может потребовать разрешения в «Настройки → Защита и безопасность»
> (macOS спрашивает про запуск скриптов). Разреши — это обычный bash-скрипт.

## Где взять токен GitHub (если хочешь публиковать сам)

Токен нужен только для того, чтобы агенту можно было заливать обновлённый график на сайт.
Он выдаётся на 1 репозиторий и его можно отозвать в любой момент:

1. Открой github.com → войди в аккаунт, у которого есть доступ к репозиторию `videoxiter/9a57a59df2fd`.
2. Правый верхний угол → **Settings** (Настройки).
3. Слева внизу → **Developer settings**.
4. **Personal access tokens** → **Fine-grained tokens** → **Generate new token**.
5. Название: `OTP schedule sync`, срок — на своё усмотрение.
6. **Repository access** → «Only select repositories» → выбери `9a57a59df2fd`.
7. **Permissions** → **Repository permissions** → **Contents** → `Read and write`.
8. Нажми **Generate token** и скопируй строку (она показывается один раз).

Вставь её в установщик, когда он спросит. Токен сохраняется только на этом компьютере,
в файле `.git/config` рабочей папки.

## Как проверить, что всё работает

- **Кнопка на сайте.** На своей «Стартовой» нажми «Синхронизировать график».
  В течение пары минут строка под кнопкой сменится на «синхронизирован ЧЧ:ММ».
- **Вручную.** В папке проекта:
  - Windows: `python scripts\sync_schedule.py --auto`
  - macOS: `python3 scripts/sync_schedule.py --auto`
  Скрипт напишет «=== синхронизация графика…» и «опубликовано: N файлов» (или «изменений нет»).
- **Лог** (macOS): `/tmp/otp-schedule-com.otp.schedule.watch.log`.

## Если что-то не так

| Симптом | Что сделать |
|---|---|
| «Не найден python3» / «python не найден» | Установи Python 3 и перезапусти установщик |
| «Нет логина/пароля Confluence» | Проверь файл `scripts/.env` в папке проекта |
| Ошибка доступа к Confluence (401/403) | Логин/пароль неверный или нет прав на страницы графиков |
| «git push не прошёл» | Нет токена или он просрочен — перевыпусти и запусти установщик заново |
| Кнопка на сайте не срабатывает | Агент должен быть запущен: проверь задачи/агентов (см. выше) |

## Для руководителя: один шаг в Supabase (делается один раз)

Агенту нужно право читать и записывать флаг «синхронизировать» в базе. Это делается
одним SQL-скриптом:

1. Открой в браузере панель Supabase своего проекта (тот, где таблицы `otp_time_events`).
2. В левом меню выбери **SQL Editor**.
3. Нажми **New query** (или плюс рядом с «SQL Editor»).
4. Открой файл `scripts/supabase_v9_sync_agent.sql` из проекта, скопируй **всё** содержимое
   и вставь в окно запроса.
5. Нажми **Run** (или Ctrl+Enter). Должно появиться `Success. No rows returned`.
6. Проверка (в том же окне):
   ```sql
   select * from public.otp_sync_flags;
   ```
   Должна быть одна строка с `id = schedule`.

Больше в Supabase ничего делать не нужно.
