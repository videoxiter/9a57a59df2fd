# Выпуск приложения «ОТП» для команды (этапы 4–5)

Порядок, который не ломает учёт времени. Каждый шаг обратим.

## 0. Что уже готово

- Приложение: `dist/OTP-tray-windows.zip` (exe + автозапуск + инструкция),
  `dist/OTP-tray-macos.zip` (скрипты запуска/сборки/автозапуска + инструкция).
- Сервер: вход по ссылке или внутреннему id (`v18`), флаг «только из приложения»
  (`v17`), список устройств и отвязка (`v19`, `v20`).
- Сайт: галочка «только из приложения» и блок «Устройства» в «Админке»;
  понятное сообщение в браузере, если старт разрешён только из приложения.

## 1. Пилот на одном сотруднике

1. Выдать свежий архив, попросить войти и начать смену.
2. Проверить, что устройство появилось: «Админка» → блок «Устройства».
3. Проверить события в канале «ДисКо»: начало смены, перерыв, возврат.
4. Включить ему галочку «только из приложения» и убедиться, что:
   - в браузере «Начать смену» показывает подсказку,
   - в приложении старт проходит.
5. При проблеме — снять галочку (доступ вернётся сразу).

## 2. Пилот на 2–3 сотрудниках

- Разные линии и графики (смены 1 и 2), разные ПК.
- Проверить: ночная смена, перезагрузка ПК, выход из сна, истечение сессии
  (через 60 дней — не в пилоте), повторный вход, отсутствие VPN.
- Сверить время в приложении и на сайте (должно совпадать до минуты).

## 3. Выпуск для команды

1. Раздать архивы, попросить войти (по одной ссылке на сотрудника).
2. Через 2–3 дня, когда у всех привязаны устройства, включить правило:
   «Админка» → «Правила для всех» (кнопка в блоке «Устройства»).
3. Сообщить команде, что смена теперь начинается из приложения, а сайт остаётся
   для просмотра и перерывов.

## 4. Откат

- Правило снять одной кнопкой «Разрешить браузер всем».
- Если приложение у кого-то не работает: сотрудник продолжает работать через
  браузер, а руководитель снимает у него галочку.
- Устройство можно отвязать в блоке «Устройства» (кнопка «Отвязать») — при
  следующем входе приложение привяжется заново.

## 5. Что проверять после выпуска

- «Админка» → «Устройства»: у всех ли сотрудников по строке.
- Канал «ДисКо»: по одному сообщению на событие (без дублей).
- Журнал часов: суммы совпадают с приложением.
- Жалобы на вход: в окне ошибки видно ответ сервера и код страницы — с этим
  можно сразу обратиться за помощью.
