# Видеоинструкция «ОТП для Windows» — производственный сценарий

Формат: **1920×1080, 16:9, 30 fps**, длительность ~1:20.
Стиль: тёмный интерфейс как на сайте (`#070b11`, акцент `#22d3ee`), крупные подписи, курсор с жёлтой обводкой.
Голос: мужской спокойный (ru-RU, профиль нейроголоса «Евгений Яковлев»).
Музыка: ambient corporate pad, приглушается (ducking) на время речи. SFX: клик и уведомление.

## Техническая реализация

- **Кадры:** Python/Pillow, 30 fps, PNG-секвенция → `ffmpeg` (libx264, yuv420p, CRF 20).
- **Курсор:** векторная стрелка с жёлтым свечением; движение по кривой Безье с easing, без рывков; клик — расходящиеся круги.
- **Подсветка:** пульсирующая рамка вокруг целевой кнопки.
- **Аудио:** озвучка сцены (mp3 → wav 48 кГц), музыка (синтез pad) с ducking −18 дБ на речи, SFX клика и уведомления.
- **Сборка:** `scripts/make_video.py`, результат — `video/ОТП-инструкция.mp4`.

### Озвучка через Speech Studio (профиль «Евгений Яковлев»)

Скрипт озвучки — тексты из таблицы выше. Если есть ключ Azure Speech:

```
POST https://<region>.tts.speech.microsoft.com/cognitiveservices/v1
Ocp-Apim-Subscription-Key: <ключ>
Content-Type: application/ssml+xml
X-Microsoft-OutputFormat: audio-24khz-48kbitrate-mono-mp3

<speak version="1.0" xml:lang="ru-RU">
  <voice name="ru-RU-DmitryNeural">
    <mstts:express-as style="friendly" styledegree="1.1">
      <prosody rate="-2%" pitch="-1%">…текст сцены…</prosody>
    </mstts:express-as>
  </voice>
</speak>
```

Без ключа используется тот же нейроголос (`ru-RU-DmitryNeural`) через открытый синтезатор —
звучание совпадает по характеру, отличается только профиль/стиль.

## Критерии приёмки

1. Курсор движется плавно (≥ 12 промежуточных позиций на переход), без телепортаций.
2. Подписи ≥ 34 px, контраст на тёмном фоне.
3. Речь без провалов, паузы ≥ 0,4 с между сценами.
4. Музыка приглушается на время речи и уходит в ноль в аутро.
5. Хронометраж ≤ 1:40.
