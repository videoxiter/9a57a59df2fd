Приложение «ОТП»
установка и работа

Учёт рабочего времени без браузера: смена, перерывы, обед, отсутствие. Напоминания о затянувшемся перерыве и открытом опросе, автоматические обновления.

Версия 1.4 · Windows 10/11 · macOS

Установка

1. Инсталлятор

Скачайте файл и запустите двойным щелчком:

https://videoxiter.github.io/9a57a59df2fd/downloads/OTP-Tray-Setup.exe

  1. Windows может показать синее окно «Система Windows защитила ваш компьютер». Нажмите «Подробнее» → «Выполнить в любом случае»: у установщика нет платной подписи.
  2. Отметьте галочки: «Создать значок на рабочем столе» и «Запускать приложение при входе в Windows» (рекомендуется).
  3. Нажмите «Установить». Программа ставится в профиль пользователя — права администратора не нужны.
  4. В конце оставьте галочку «Запустить ОТП сейчас» — приложение стартует сразу.
После установки ярлык появляется в меню «Пуск» → «ОТП». Удаление — «Параметры → Приложения → ОТП…» (ярлыки и автозапуск убираются автоматически).
Первый запуск

2. Вход

Окно входа приложения (реальный вид программы)
  1. Вставьте ссылку на свою страницу (её присылает руководитель) или только код из неё. Если ссылка уже в буфере обмена, она подставится сама.
  2. Введите пароль. Сомневаетесь в опечатке — поставьте галочку «показать пароль».
  3. Нажмите «Войти». Значок в трее появляется только после успешного входа — это нормально.
Если написано «Неверный пароль или ссылка» — в окне ошибки видно ответ сервера и код страницы. С этим текстом можно сразу обратиться к руководителю.

Работа

4. Меню и действия

Щелчок по значку открывает меню: Начать смену, Техперерыв 1/2, Обед, Вернуться с перерыва, Временное отсутствие, Завершить смену.

Перед применением идёт отсчёт 10 секунд с кнопкой «Отмена»: если нажали случайно — успеете отменить. Повторный щелчок по тому же пункту применяет сразу.

Горячие клавиши (Windows)

СочетаниеДействие
Ctrl+Alt+Sначать смену
Ctrl+Alt+Bтехперерыв 1 (повторно — вернуться)
Ctrl+Alt+Lобед (повторно — вернуться)
Ctrl+Alt+Aвременное отсутствие
Ctrl+Alt+Rвернуться с перерыва
Ctrl+Alt+Eзавершить смену

Свои сочетания: меню → «Горячие клавиши…». Работают и при свёрнутом приложении.

Напоминания

  • Перерыв идёт дольше нормы (техперерыв 15 мин, обед 60, отсутствие 30) — уведомление в трее.
  • Изменились данные на странице (график, бонусы, награды) — сообщение «Новое на странице: …».
  • Открыт опрос по графику, а пожелания не отправлены — напоминание.

6. Сборка графика

Сетка «люди × дни», автосборка по пожеланиям, проверка норм и линии на день
  • Авто по пожеланиям — расставляет смены по правилам линий и пожеланиям.
  • Проверить нормы — покажет недоборы по линиям.
  • Публиковать — график уходит на сайт, сотрудники видят его в личной странице.
  • XLSX с цветами и В Confluence — выгрузки для отчёта.
