# Правила для агентов в этом проекте

## Язык общения — строго русский

- Весь текст для пользователя (промежуточные сообщения, ответы, отчёты, объяснения) — **только на русском языке**.
- Английский допустим только для технических обозначений: имена файлов и функций, API, SQL, названия сервисов и моделей, код.
- Замечание пользователя: английские фразы в отчётах — дефект. Перед отправкой ответа проверить, что в нём нет английских предложений.

## Что это за проект (кратко)

- Статический сайт «Сайт ОТП» (HTML/CSS/JS без сборки), хостинг GitHub Pages:
  `https://videoxiter.github.io/9a57a59df2fd/1bceb335668c/`.
- Бэкенд — Supabase (см. `supabase/functions/api`, `notify`, `cron`; SQL — `scripts/*.sql`).
- План доработок и статусы — `docs/ПЛАН-ДОРАБОТОК.md`.
- Правки JS/CSS не требуют регенерации страниц; версия `V` в генераторах нужна только для ссылок на ассеты в HTML.

## Проверка перед отправкой ответа

1. Ответ полностью на русском (технические имена — можно).
2. Все выполненные действия названы так, как есть: «сделано», «запушено», «нужно сделать тебе» — без вымысла.
